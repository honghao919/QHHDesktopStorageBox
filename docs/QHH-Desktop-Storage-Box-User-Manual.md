# QHH Desktop Storage Box 用户说明书

版本：1.3.15

适用平台：Windows 10 / 11 x64

## 1. 软件简介

QHH Desktop Storage Box 是一款基于原生 WPF 构建的轻量级 Windows 桌面文件收纳工具。它可以把常用文件、工作目录、临时资料和待办事项整理到桌面收纳盒中，同时保持文件操作安全、可追踪、可还原。

主要特点：

- 普通收纳盒会把文件移动到应用数据目录。
- 映射收纳盒只保存源文件路径，不移动、不复制、不删除源文件。
- 临时收件箱适合先收集文件，之后再分类。
- 智能收纳盒按目录、名称、扩展名和修改时间自动维护路径引用。
- 支持批量操作、导入预检、重名处理和最近操作撤销。
- 快捷面板支持文件名、完整路径、中文全拼和拼音首字母搜索。

## 2. 安装和启动

### 安装版

1. 双击 `QHHDesktopStorageBox-Setup-v1.3.15-x64.exe`。
2. 按安装向导完成安装。
3. 可选择创建桌面图标和开机启动。
4. 从开始菜单或桌面图标启动 QHH Desktop Storage Box。

### 便携版

1. 解压 `QHHDesktopStorageBox-v1.3.15-win-x64.zip`。
2. 运行 `QHHDesktopStorageBox.App.exe`。
3. 不要单独移动 EXE 文件。ZIP 内可能有 WPF 运行所需的附属文件，应保持目录完整。

### 系统要求

- Windows 10 或 Windows 11，推荐 Windows 11。
- 64 位 Windows。
- 安装版已包含运行时，不需要另外安装 .NET。

## 3. 第一次使用

首次启动会自动创建：

- 普通收纳盒
- 映射收纳盒
- 临时收件箱

应用数据默认保存在：

```text
%LocalAppData%\QHHDesktopStorageBox\
  qhhdesktopstoragebox.db
  Boxes\{BoxId}\
  logs\
```

旧版 WitchDrawer 数据会在首次启动新版本时自动迁移到新目录。迁移失败时，程序会继续使用旧目录，避免出现数据看似丢失的情况。

## 4. 收纳盒类型

### 普通收纳盒

拖入的文件或文件夹会实际移动到应用数据目录。删除项目时，文件会恢复到原来的位置；如果原目录不存在，会恢复到桌面。

普通盒和像素盒支持两种显示方式：

- **网格视图**：显示大图标，适合桌面摆放。
- **列表视图**：以紧凑行显示名称，适合项目较多时快速浏览。

视图选择按每个收纳盒分别保存，不会影响其他盒子。

适合：

- 临时下载文件
- 等待分类的资料
- 由应用统一管理的文件

不建议把正在被其他程序使用的项目长期放在普通盒中。

### 映射收纳盒

只记录文件的绝对路径，源文件始终留在原位置。删除项目只会删除引用，不会影响源文件。

适合：

- 项目和代码目录
- 工作资料目录
- 网络位置或经常被其他程序使用的文件

### 临时收件箱

用于先收集、后整理。文件会移动到收件箱数据目录，可以继续移动到其他普通盒。

### 智能收纳盒

智能盒会根据规则自动维护路径引用。规则可以配置：

- 监控文件夹
- 名称包含的关键字
- 扩展名，例如 `.pdf,.docx,.xlsx`
- 最近修改天数
- 最多项目数

智能盒只更新引用，不移动、不复制、不删除源文件。

### 系统应用

普通盒和映射盒可以加入 Windows 开始菜单中的应用：

1. 打开收纳盒标题栏上的“添加系统应用”按钮。
2. 搜索应用名称或应用标识。
3. 选择应用并点击“添加应用”。

部分 Windows 版本也支持直接把开始菜单中的应用拖入收纳盒。

- 传统 Win32 程序保存可执行文件或快捷方式路径引用。
- UWP、商店应用保存 `shell:AppsFolder` 应用标识。
- 系统文件不会被移动、复制或删除。
- 如果应用被卸载、移动或开始菜单条目被删除，引用可能失效。

### 待办收纳盒

用于记录任务。支持添加、完成、编辑、删除、撤销删除和归档。

### 抽屉收纳盒和像素收纳盒

两者主要用于桌面视觉与交互风格。抽屉盒支持展开式布局，像素盒使用像素化图标与圆角效果。

## 5. 文件操作

### 拖入文件

1. 从资源管理器选择文件或文件夹。
2. 拖到目标收纳盒。
3. 普通盒和收件箱会移动文件；映射盒和智能盒只保存引用。

系统应用是引用项，不会移动程序文件。普通盒中的系统应用同样只保存引用。

### 批量操作

在控制台文件列表中使用：

- `Ctrl + 单击`：追加或取消选择。
- `Shift + 单击`：选择连续范围。
- `Delete`：批量删除当前选择。

选中后可以批量打开、导出到桌面、移动或删除。

### 导入预检

导入大文件夹、跨盘项目或重名文件时，程序会显示预检信息：

- 项目数量
- 文件数量
- 总大小
- 是否跨盘
- 是否存在同名项目

可选择：

- 保留两份并自动添加后缀。
- 跳过同名项目。
- 取消本次导入。

### 操作撤销

程序会记录导入、移动、导出和删除操作。顶部撤销按钮可以撤销最近一次文件操作。

撤销会尽量恢复：

- 文件位置
- 数据库项目记录
- 原收纳盒归属

如果文件被其他程序修改、移动或删除，撤销可能失败，程序会显示原因。

## 6. 快捷面板

默认快捷键：

```text
Ctrl + Alt + W
```

快捷面板支持：

- 文件名搜索
- 完整路径搜索
- 收纳盒名称搜索
- 中文全拼搜索
- 拼音首字母搜索
- `↑` / `↓` 选择项目
- `Enter` 打开项目
- `Esc` 关闭面板

如果快捷键无法注册，通常是其他程序已经占用该组合。可以在设置页重新设置快捷键。

## 7. 设置

设置页支持：

- 主题切换
- 盒子和图标透明度
- 自动隐藏
- 图标名称显示模式
- 快速面板快捷键
- 桌面盒布局备份与恢复
- 数据存储位置迁移
- 完整数据备份与恢复
- 映射盒和智能盒失效引用检查
- 诊断报告生成
- 开机自启动
- 隐藏桌面图标
- 双击桌面切换图标
- 更新检查

### 数据目录迁移

迁移前请关闭可能占用盒内文件的程序。迁移会复制数据库、盒内文件、日志和设置。迁移完成后需要重启应用。

原目录默认保留为备份。

### 完整数据备份

在“数据安全与恢复”中选择“创建完整备份…”，然后选择 ZIP 保存位置。备份包含：

- SQLite 数据库
- 普通盒、抽屉盒、像素盒和收件箱的文件
- 备份格式、程序版本和创建时间清单

映射盒和智能盒只保存引用，因此备份不会复制它们指向的源文件。重要的映射目录应使用其他方式单独备份。

### 从备份恢复

1. 点击“从备份恢复…”。
2. 选择由本程序创建的 ZIP 备份。
3. 选择一个空文件夹作为恢复目标。
4. 等待程序验证备份清单、数据库和文件路径。
5. 恢复成功后立即重启应用。

程序不会覆盖当前正在使用的数据目录。恢复后如发现问题，原数据目录仍然保留。

### 数据库升级保护

数据库结构升级前，程序会自动在以下位置保留升级前备份：

```text
%LocalAppData%\QHHDesktopStorageBox\Backups\
```

程序保留最近 5 个版本化数据库备份，并自动清理更早的记录。

### 检查失效引用与诊断报告

- “检查失效引用”会扫描映射盒和智能盒的源路径，只读取状态，不移动、不复制、不删除文件。
- “生成诊断报告…”会汇总版本、系统、数据目录、磁盘容量、收纳盒数量、项目数量、失效引用和最近日志。
- 诊断报告会把用户主目录替换为 `%USERPROFILE%`，但在发送给他人前仍应人工检查是否包含敏感文件名。

## 8. 更新

应用会从 GitHub Releases 检查新版本。下载更新前会进行域名限制和 SHA-256 校验。

正常启动后，应用会自动检查最新版本：

- 自动检查最多每 12 小时执行一次。
- 发现新版本时会提示是否下载并更新。
- 开机静默启动不会弹出更新窗口，可在设置页手动检查。
- 网络失败不会影响应用启动或文件操作。

更新流程：

1. 下载更新包。
2. 退出当前实例。
3. 备份当前程序目录。
4. 覆盖安装目录。
5. 启动新版本并写入启动成功标记。
6. 启动失败时自动回滚。

## 9. 卸载

可以通过 Windows“设置 > 应用”或开始菜单卸载 QHH Desktop Storage Box。

卸载程序会删除安装目录中的程序文件，不会删除 `%LocalAppData%\QHHDesktopStorageBox` 中的用户数据。

如需彻底清理，请在确认不再需要数据后手动删除：

```text
%LocalAppData%\QHHDesktopStorageBox
```

如果曾迁移数据目录，还应删除设置中最后选择的自定义数据目录。

## 10. 隐私说明

- 数据库、文件、日志和设置只保存在本机。
- 应用不会上传文件、文件名、搜索记录、数据库、日志或使用统计。
- 应用只连接本项目的 GitHub 仓库检查更新和下载更新包。
- 更新下载限制在本项目仓库和 GitHub 官方 Release 资产域名。
- 更新包必须具有 Release 中发布的 SHA-256，校验失败时不会解压或安装。

## 11. 常见问题

### 程序无法接收桌面拖放

请勿以管理员身份运行。管理员进程和普通桌面处于不同完整性级别，Windows 会阻止拖放。

### 快捷键无效

`Ctrl + Alt + W` 可能被其他程序占用。请在设置页更换快捷键。

### 文件无法移动

可能原因：

- 文件正在被其他程序使用。
- 源目录无访问权限。
- 目标磁盘空间不足。
- 路径过长。
- 网络盘断开。

请关闭占用文件的程序后重试。

### 删除后文件去了哪里

普通盒、收件箱、抽屉盒和像素盒会优先把文件恢复到原位置。原目录不存在时恢复到桌面。

映射盒和智能盒删除的只是引用，源文件不会移动。

### 如何备份

推荐使用设置页的“创建完整备份”。也可以在关闭应用后复制整个数据目录：

```text
%LocalAppData%\QHHDesktopStorageBox
```

数据库和 Boxes 目录必须一起备份。

## 12. 文件安全说明

- 普通盒移动文件前会检查目标路径是否位于应用存储目录内。
- 不支持符号链接等重解析点，避免路径逃逸。
- 跨盘移动使用复制后删除，并在删除前校验目录快照。
- 文件名冲突自动使用 ` (1)`、` (2)` 等后缀。
- 存储盘暂时离线时，程序不会把“不可见”误判为“已删除”。
- 映射盒和智能盒不会修改源文件。
- 系统应用只保存启动引用，不会移动系统安装目录。
- 数据库结构升级前会自动保留版本化备份。
- 备份恢复只写入空文件夹，验证失败时不会切换到恢复数据。
